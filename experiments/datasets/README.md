# Datasets

Datasets are immutable, named evaluation assets. Their contents are DVC-tracked; their schema,
guidance, and DVC pointer files are Git-tracked.

`golden_v0` is an immutable pilot dataset for refining per-post semantic extraction. It is not a
final model benchmark and contains no post-level information-attack label. It is evaluated only
through the deterministic, versioned `GoldenV0Adapter`; its source JSONL is never migrated in
place. `golden_v1` is the frozen native schema for the subsequent 45 held-out annotations.

The canonical evaluator input is generated by `load_golden()`. It retains adapter actions,
warnings, unmapped legacy-only rhetoric labels, and ambiguous mappings so exclusions remain
visible in every benchmark report.
